1 Przygotowanie Maca

Homebrew jest wymagany do automatycznej aktualizacji aplikacji. Jeżeli jest już zainstalowany, ten krok wykonujesz tylko kontrolnie.

ℹ️
Najpierw sprawdź Homebrew

Otwórz Terminal na komputerze klienta i wykonaj poniższą komendę.

Sprawdzenie Homebrew 
brew --version

✅ Homebrew jest zainstalowany

Jeżeli Terminal pokaże wersję Homebrew, możesz przejść bezpośrednio do wyboru aplikacji.

❌ command not found: brew

Jeżeli Terminal nie zna polecenia brew, zainstaluj Homebrew poniższą oficjalną komendą.

Instalacja Homebrew

Oficjalny instalator Homebrew 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
⚠️
Po instalacji przeczytaj komunikat Terminala

Homebrew może poprosić o dodanie go do PATH. Instalator pokaże dokładną komendę do wykonania.

Jeżeli brew nadal nie jest widoczny

Apple Silicon — M1 / M2 / M3 / M4 / M5

/opt/homebrew 
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Intel

/usr/local 
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"
